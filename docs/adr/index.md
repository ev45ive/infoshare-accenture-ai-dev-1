# Architecture Decision Records (ADR)

Rejestr istotnych decyzji architektonicznych. Każda decyzja to osobny plik `NNNN-krotki-tytul.md`.

## Statusy

`Proposed` → `Accepted` → `Deprecated` / `Superseded by NNNN`

## Szablon

```markdown
# NNNN. Tytuł decyzji

- Status: Proposed
- Data: RRRR-MM-DD

## Kontekst
Jaki problem i jakie ograniczenia.

## Decyzja
Co wybieramy.

## Alternatywy
Co rozważono i dlaczego odrzucono.

## Konsekwencje
Zalety, koszty, ryzyka.
```
